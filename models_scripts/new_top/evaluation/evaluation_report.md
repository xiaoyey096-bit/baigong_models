# 当前离线结果基线

本报告记录当前固定 Top10 算法的运行检查结果，不是人工金标准评测结论。

## 算法口径

- 每岗先取 BGE Embedding Top10；
- 精确规则只扫描 `major_requirement_raw`；
- 规则命中的专业只在 Embedding Top10 内提前；
- 不使用模糊映射、别名、小类展开或 Reranker；
- 每岗最终固定 10 条。

## 当前评测集状态

`evaluation/llm_blind_labels.csv` 只有 50 个岗位、704 条候选记录，属于 LLM 初步盲审样本，不是人工金标准。正式测试集构建规范见同目录 `HANDOFF_QA.md`：300 个分层岗位，LLM 初标后人工确认，保存 0/1/2 相关等级并评估 Recall@5/10、Precision@5/10 和 NDCG@5/10。
